# Laboratorio Pymes

Herramientas gratuitas, en español y sin registro, para el marketing y la gestión de pequeñas empresas. Se usan desde el navegador y **tus datos no salen de tu equipo**.

👉 **Catálogo en vivo:** https://freyesperales.github.io/laboratorio-pymes/

Cada lunes, miércoles y viernes se publica una herramienta nueva: marketing, gestión y finanzas, ventas y atención. Cada una trae una demo en vivo, una guía de uso y la forma de instalarla en tu web.

Las construye un agente de IA que dirige [Francisco Reyes](https://farp.dev), de la agencia [LAURA](https://laura.lat). ¿Necesitas algo a medida? [Escríbenos por WhatsApp](https://wa.me/56999968482).
